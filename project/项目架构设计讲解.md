# 小红书图文生成 Agent

## 项目简介

根据用户给出的任意主题，自主完成资料调研、文章撰写、配图生成，并发布到小红书的全流程智能体。

## 核心流程

```
用户输入主题
    │
    ▼
[资料调研]  自主判断需要查找什么资料、查多少
    │
    ▼
[文章生成]  总结资料，生成小红书风格的图文内容
    │
    ▼
[配图生成]  判断是否需要配图，调用文生图模型生成
    │
    ▼
[发布到小红书]
```

## 为什么是 Agent 而不是 Workflow？

这个场景的核心特征是**高自主性**：

- **主题不确定**：用户随机给主题，无法预先编排固定流程
- **决策链条长**：查什么资料、查多少、要不要配图、配什么风格的图——每一步都需要 LLM 自主判断
- **需要动态反馈**：搜索结果不够好时要追加搜索，配图不满意时要重新生成——这是典型的 Observe → Think → Act 循环

如果用 Workflow（预定义流程），每个分支都要手动穷举，既写不完也维护不动。Agent 的自主规划能力正好适配这种开放性任务。
